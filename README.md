# POE2 AstrBot 插件

查询 POE2 传说装备市集价格、物品属性、词条查询、通货比例

## 功能特性

- 🔮 传说装备市集查价 (官方 trade2 API)
- 💱 通货比例查询 (poe2scout.com API)
- 🔍 传说装备属性查询 (本地数据 + poe2wiki API)
- 🌐 支持简体/繁体/英文三语搜索
- 🔤 词缀自动汉化 (250+ 条)
- 📦 440+ 传说装备数据库
- 🔄 热重载 (无需重启 AstrBot)

## 命令列表

### 市集查价 (官方 trade2 API)

| 命令 | 说明 |
|------|------|
| `poe2 设置sessid <ID>` | 设置 POESESSID 启用查价 |
| `poe2 物价 <名称>` | 查询传说装备价格 (显示前20个) |
| `poe2 查看 <卖家名/序号>` | 查看卖家物品详情 (词缀汉化) |
| `poe2 通货 [A] [B]` | 查询通货比例 |
| `poe2 高级搜索 <物品> [价格] [货币]` | 带价格上限过滤 |
| `poe2 词缀搜索 <物品> <词缀ID> <值>` | 按词缀条件搜索 |
| `poe2 词缀数据` | 查看可用词缀 ID 列表 |

### 传说装备查询

| 命令 | 说明 |
|------|------|
| `poe2 属性 <属性名> [页码]` | 搜索带该属性的装备 |
| `poe2 装备 <装备名/序号>` | 按装备名搜索 (单个结果直接显示详情) |

### 系统命令

| 命令 | 说明 |
|------|------|
| `poe2 重载` | 热重载插件 (无需重启 AstrBot) |
| `poe2 帮助` | 显示帮助信息 |

## 配置文件

配置文件路径：`config.json`

```json
{
  "league": "runesofaldur",
  "game": "poe2",
  "poesessid": "你的POESESSID",
  "trade_api_enabled": true,
  "trade_league": "Runes of Aldur",
  "cache_duration_minutes": 30
}
```

| 字段 | 说明 |
|------|------|
| `league` | 构筑赛季 |
| `game` | 游戏版本 (poe2) |
| `poesessid` | 官方网站登录凭证 |
| `trade_api_enabled` | 是否启用交易 API |
| `trade_league` | 交易赛季 |
| `cache_duration_minutes` | 缓存时间 (分钟) |

## 获取 POESESSID

1. 登录 https://www.pathofexile.com
2. 按 F12 打开开发者工具
3. 切换到 Application/存储 标签
4. 在 Cookies 中找到 POESESSID
5. 复制值并使用 `poe2 设置sessid <值>` 设置

## 词缀汉化

插件内置 250+ 条词缀汉化映射，包括：

- 护符相关 (护符栏位、充能)
- 药剂相关 (回复、立即生效)
- 戒指相关 (左手/右手加成)
- 元素伤害 (火焰/冰霜/闪电/混沌)
- 防御属性 (护甲/闪避/能量护盾)
- 攻击属性 (暴击/攻速/施法速度)
- 基础属性 (力量/敏捷/智慧)

查看词缀详情时自动汉化为简体中文。
